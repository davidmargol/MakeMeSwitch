MakeMeSwitch

Turn an ordinary Debian or Ubuntu computer into a managed Ethernet switch using Open vSwitch, a Cisco-inspired CLI, and a web dashboard.

Quick install

curl -fsSL https://davidmargol.github.io/MakeMeSwitch/install.sh | sudo bash

Remote-safe install

Keeps host SSH on port 22 and leaves physical NICs unassigned until you configure them:

curl -fsSL https://davidmargol.github.io/MakeMeSwitch/install.sh | sudo bash -s -- --keep-ssh-22 --no-attach-all
Supported platforms: Debian 12+ and Ubuntu 22.04+. Pass any install.sh flag after --.
